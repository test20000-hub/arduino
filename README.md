# 2026 군포중앙고등학교 정보 수업 대시보드 🚀

군포중앙고등학교 정보·전자공학 실습 및 아두이노 수업 과제 수행을 위한 빠른 이동 포털 페이지입니다.

---

## 📌 주요 기능 & 메뉴 (Main Features)

- **구글 드라이브 (Google Drive)**: 수업 관련 클라우드 파일 보관함 및 학습 자료 이동
- **구글 클래스룸 (Google Classroom)**: 수업 자료 확인 및 과제 제출
- **틴커캐드 (Tinkercad Circuits)**: 온라인 아두이노 회로 시뮬레이터 및 코드 실습 환경
- **과제 3-2 정답 센터**: 회로 분석 및 코드 문항별 정답 자동 조회 및 자가진단 시스템 (`answer.html`)

---
