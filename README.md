# arduino

# 🤖 아두이노 스위치 및 LED 제어 실습 (과제 3-2)

이 프로젝트는 아두이노의 디지털 입출력(Digital I/O), 풀업/풀다운 저항의 작동 원리, 조건문(`if-else`)을 이용한 스위치 제어 코드를 분석하고 학습하기 위한 자료입니다.

---

## 📌 주요 학습 내용
- **디지털 입력/출력**: `digitalRead()`, `digitalWrite()` 함수 활용
- **회로 및 전압 분석**: 5V, GND(0V) 및 스위치 입력을 위한 풀업 저항 원리 이해
- **C/C++ 제어 문법**: `pinMode()`, `if-else` 조건문, 들여쓰기(Indentation) 및 블록(`{ }`) 구조 분석

---

## 💡 자주 틀리는 핵심 오답 노트 (주의사항)

> ⚠️ **제출 전 필수 점검**
> 1. **13번 줄 (`swR`)**: `swR`은 **오른쪽 스위치** 값을 저장하는 변수입니다. (*'왼쪽 스위치'로 오기하지 않도록 주의*)
> 2. **24번 줄 핀 번호**: 왼쪽 스위치가 눌렸을 때 제어하는 LED는 **8번 핀**입니다. (`digitalWrite(8, HIGH);`)

---

## 📋 문항별 모범답안 및 해설

### 1. 회로 및 전압 관련 (Q1 ~ Q12)
| 번호 | 질문 요약 | 정답 및 핵심 해설 |
| :---: | :--- | :--- |
| **Q1** | 오른쪽 아래 빨간선 위치 및 전압 | **5V 핀** 연결 / **5V** |
| **Q2** | 왼쪽 위아래 빨간선 전압 | **5V** |
| **Q3** | 오른쪽 아래 까만선 전압 | **0V** (GND) |
| **Q4** | 1kΩ 저항 아랫쪽 다리 전압 및 일정 여부 | **5V** / 5V 핀에 직접 연결되어 **일정함** |
| **Q5** | 330Ω 저항 아랫쪽 다리 전압 및 일정 여부 | **0V** / GND에 직접 연결되어 **일정함** |
| **Q6** | 스위치를 눌렀을 때 초록선 전압 | **0V** (GND와 연결됨) |
| **Q7** | 스위치를 안 눌렀을 때 초록선 전압 | **5V** (5V 전원에서 들어옴) |
| **Q8** | 왼쪽 스위치 누를 때 4번 핀 입력 전압 | **0V** (GND와 연결됨) |
| **Q9** | 오른쪽 스위치 안 누를 때 3번 핀 전압 | **5V** (5V 전원에서 들어옴) |
| **Q10**| 스위치 오른쪽 아래 까만선 역할 | **접지 (GND)** |
| **Q11**| 7번 핀 5V 출력 시 동작 | 7번 핀(5V) → 초록선 → 저항 → LED 양극(+) → 음극(-) 흘러 **LED 켜짐** |
| **Q12**| 6번 핀 0V 출력 시 동작 | 6번 핀이 GND(0V)와 같아 전위차가 없으므로 **전류가 안 흘러 LED 꺼짐** |

### 2. 코드 문법 및 setup() 함수 (Q13 ~ Q19)
| 번호 | 질문 요약 | 정답 및 핵심 해설 |
| :---: | :--- | :--- |
| **Q13**| `setup()` 뒤 `()`의 의미 | **함수**임을 알리며 전달할 입력값(인수)이 없음 |
| **Q14**| `setup`의 정의 | **함수 이름** |
| **Q15**| `{ }` 중괄호의 의미 | **함수의 시작과 끝** 영역 지정 |
| **Q16**| 코드 들여쓰기 이유 | 코드의 **하위 구성을 명확히 구분**하고 가독성을 높이기 위함 |
| **Q17**| `pinMode(3, INPUT);` 세부 구조 | `M`(낙타표기법), `()`(매개변수), `3`(3번 핀), `INPUT`(입력모드), `,`(구분), `;`(마침표) |
| **Q18**| `OUTPUT`의 의미 | 핀을 **출력 모드**로 설정 |
| **Q19**| `setup()` 함수의 특징 | 전원 투입 시 **최초 1회 실행**, 초기 설정 담당, 생략 불가 |

---

### 3. loop() 함수 및 조건문 (Q20 ~ Q32)
| 번호 | 질문 요약 | 정답 및 핵심 해설 |
| :---: | :--- | :--- |
| **Q20**| `void loop()`의 `()` 의미 / `loop` | 입력값이 없는 **함수** / **함수 이름** |
| **Q21**| `loop()`의 `{ }` 및 들여쓰기 | `loop` **함수 블록의 시작과 끝** / 하위 코드 구분 |
| **Q22**| `int swL, swR;` 의미 | `int`(정수 변수 선언), `swL`(왼쪽 스위치), `swR`(오른쪽 스위치) |
| **Q23**| `swR = digitalRead(3);` 의미 | 3번 핀 신호를 읽어 `swR`에 저장 (`1` 또는 `0`) |
| **Q24**| 16번 줄 `digitalRead( )` 빈칸 | **`4`** (`setup`에서 4번 핀을 왼쪽 스위치 입력으로 설정) |
| **Q25**| `if(swR==LOW)` 구조 | `LOW`(0V), `swR`(오른쪽 스위치 값), 참일 때(18번 줄), 거짓일 때(20번 줄 `else`) |
| **Q26**| `digitalWrite(6, HIGH);` 동작 | **6번 핀**으로 5V 전압을 출력하여 오른쪽 LED를 켬 |
| **Q27**| 20번 줄 `else {` 빈칸 정답 | **`if`**, **`if`**, **`i`**, **`}`** |
| **Q28**| `digitalWrite(6, LOW);` 시점 및 의도 | 스위치를 **안 누를 때** 실행 / LED를 **끄기 위함** |
| **Q29**| `loop()` 특징 / 22번 줄 `}` 위치 | **무한 반복 실행** / 상위 `else`문과 들여쓰기 열 맞춤 |
| **Q30**| 23번 줄 `if( )` 빈칸 식과 이유 | **`swL == LOW`** / 왼쪽 스위치 눌림 상태를 확인하기 위함 |
| **Q31**| 24번 줄 `digitalWrite( , HIGH);` 빈칸 | **`8`** / 왼쪽 스위치 작동 시 대응하는 **8번 LED**를 켜기 위함 |
| **Q32**| 26~28번 줄 `else` 블록 의미 | 왼쪽 스위치에서 손을 떼었을 때 **8번 LED를 끄는 실행 구문** |
